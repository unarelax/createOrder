# 蔬菜开单

给蔬菜批发摊用的手机开单工具。点品类、按斤敲数量、出大字小票，把图片或文字发微信给客户。

先做**网页版**：放到公网、设开机密码、添加到主屏幕后没网也能用。老板用顺、确认没问题之后，再考虑套壳做成安装包。

纯前端，无后端、无账号。单据存在这台手机的浏览器里。

## 怎么用起来

**手机上（推荐）**

1. 把整个文件夹放到任意 **HTTPS** 静态空间（Nginx、GitHub Pages、对象存储静态网站都行），手机浏览器打开。
2. 第一次会建议设 **4 位开机密码**，避免别人打开同一个网址看见单据。
3. 点浏览器菜单里的「添加到主屏幕」，之后像 App 一样点图标进入；没网也能开单。

**电脑上试用**

直接双击 `index.html` 就能打开。双击本地文件时，开机密码可以用，离线缓存（Service Worker）不会生效，这是浏览器限制。

## 开一单的操作

1. 点左边的品类（生姜、大蒜、山药、红薯……）
2. 敲数量，按斤，支持小数，比如 `12.5`
3. 接着点下一个品类，上一行会自动入账
4. 需要的话点小票上的「车号」「备注」填进去，备注可以写客户姓名电话
5. 按绿色的「完成本单」，弹出小票图，长按保存到相册，或者点「复制文字」

小票图是「大字账本表」：带序号列，数量 / 单价 / 金额都大，合计最大。打错了点小票上已经入账的那一行，可以改数量、改单价、删除。

## 几个容易忽略的地方

- **改价有两种**。开单页的「改价」只影响当前这一单；弹窗里勾上「同时存为默认价」才会长期生效。要长期改名称、单位、排序，去「☰ → 品类管理」。
- **单号不会浪费**。单号只在按下「完成本单」时才占用，中途清空草稿不消耗号。
- **历史单据是快照**。以后涨价、改名、删品类都不会改动已经开过的单。
- **开机密码只挡界面**。密码不对就进不去，但数据仍在这台手机的浏览器里，不是加密保险柜。忘记密码只能清空本机数据后重来。
- **记得备份**。清理浏览器数据或者换手机就没了。「☰ → 设置」里可以导出备份文件，或者复制一段备份文本发到微信收藏。

## 默认品类

首次使用预置四样（都可以在品类管理里改）：

| 品类 | 单位 | 参考单价 |
| --- | --- | --- |
| 生姜 | 斤 | 6 元 |
| 大蒜 | 斤 | 5 元 |
| 山药 | 斤 | 9 元 |
| 红薯 | 斤 | 3 元 |

店名默认「蔬菜批发」，可在设置里改成自己的摊名。

## 文件结构

```
index.html        页面骨架，四个页面容器与全部弹窗
css/app.css       全部样式
js/store.js       数据层：商品 / 订单 / 设置 / 单号 / 车号 / 开机密码
js/receipt.js     小票中间层：订单对象转成结构化文本行
js/export.js      原生 canvas 画 V1 大字账本表、导出 PNG、复制文字、下载备份
js/keypad.js      数量输入规则与车牌省份键盘
js/app.js         页面切换、开单状态机、PIN 锁、各页面渲染
manifest.json     添加到主屏幕用的应用信息
sw.js             离线缓存
icons/            主屏幕图标
```

小票图片是用 `canvas` 逐行手绘的，没有引入 html2canvas 之类的库，所以没网也能出图。

## 数据存放位置

浏览器 localStorage，键名如下：

| 键 | 内容 |
| --- | --- |
| `bm.products.v2` | 品类列表 |
| `bm.orders.v2` | 历史单据（含行快照） |
| `bm.settings.v2` | 店名、副标题、页脚 |
| `bm.seq.v2` | 每天的单号计数 |
| `bm.plates.v2` | 最近用过的车号 |
| `bm.pin.v2` | 开机密码（加盐哈希，不是明文） |

以前建材店试用留下的 `bm.*.v1` 不会自动带过来，避免开单页还出现水泥砂石。
