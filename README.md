# 建材店快速开单

给建材店老板用的手机开单工具。点品类、敲数量、出小票，把图片或文字发微信给客户。

纯前端，无后端、无账号、无外部依赖，断网也能用。所有数据存在这台手机的浏览器里。

## 怎么用起来

**手机上（推荐）**

1. 把整个文件夹放到任意静态服务器上（内网、Nginx、GitHub Pages 都行），手机浏览器打开 `index.html`。
2. 打开后点浏览器菜单里的「添加到主屏幕」，之后就像一个 App 一样点图标进入。

**电脑上试用**

直接双击 `index.html` 就能打开，不需要装任何东西，也不需要启动服务器。

## 开一单的操作

1. 点左边的品类（水泥、砂石……）
2. 敲数量，支持小数，比如 `2.5`
3. 接着点下一个品类，上一行会自动入账
4. 需要的话点小票上的「车号」「备注」填进去，备注可以写客户姓名电话
5. 按绿色的「完成本单」，弹出小票图，长按保存到相册，或者点「复制文字」

打错了不用重来：点小票上已经入账的那一行，可以改数量、改单价、删除。

## 几个容易忽略的地方

- **改价有两种**。开单页的「改价」只影响当前这一单；弹窗里勾上「同时存为默认价」才会长期生效。要长期改名称、单位、排序，去「☰ → 品类管理」。
- **单号不会浪费**。单号只在按下「完成本单」时才占用，中途清空草稿不消耗号。
- **历史单据是快照**。以后涨价、改名、删品类都不会改动已经开过的单。
- **记得备份**。数据只在这台手机的浏览器里，清理浏览器数据或者换手机就没了。「☰ → 设置与备份」里可以导出备份文件，或者复制一段备份文本发到微信收藏，换手机时再导入回来。

## 文件结构

```
index.html        页面骨架，四个页面容器与全部弹窗
css/app.css       全部样式
js/store.js       数据层：商品 / 订单 / 设置 / 单号 / 车号的读写与金额计算
js/receipt.js     小票中间层：订单对象转成结构化文本行
js/export.js      原生 canvas 画小票、导出 PNG、复制文字、下载备份
js/keypad.js      数量输入规则与车牌省份键盘
js/app.js         页面切换、开单状态机、各页面渲染与事件
```

小票图片是用 `canvas` 逐行手绘的，没有引入 html2canvas 之类的库，所以没网也能出图。

## 数据存放位置

浏览器 localStorage，键名如下：

| 键 | 内容 |
| --- | --- |
| `bm.products.v1` | 品类列表 |
| `bm.orders.v1` | 历史单据（含行快照） |
| `bm.settings.v1` | 店名、副标题、页脚 |
| `bm.seq.v1` | 每天的单号计数 |
| `bm.plates.v1` | 最近用过的车号 |

## 目前不做的事

赊账台账、客户档案、多设备同步、小票打印机。收没收钱看微信转账记录，这个工具只负责把单开清楚。
